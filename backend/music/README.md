# Music API

Owns genres, albums, tracks, uploaded audio/covers, lyrics, collaborators, public discovery,
Gold early access, download permission, listening history, stream counting, and statistics.
A stream counts after 30 server-verified listened seconds; Basic users are limited to
60 counted streams per day. The home endpoint also returns deterministic recommendations
weighted by listening-history artist and genre affinity, with popularity used only as a
tie-breaker or cold-start fallback.
